# 本番公開前チェックリスト

サーバーを一般公開する前に、次を確認してください。

## 基本設定

- [ ] データベースに `postgres` または `d1` を設定した。
- [ ] `npm run migrate` を実行してテーブルを作った。
- [ ] 画像の保存先を設定した。
- [ ] `npm run check:config` で設定エラーが出ない。

## セキュリティ

- [ ] `server/.env` のパスワードや秘密キーを Git にコミットしていない。
- [ ] 不要なテストアカウントやデバッグ設定を無効にした。

## 主な機能

- [ ] アカウント登録とログインができる。
- [ ] 投稿、画像添付、いいね、返信ができる。
- [ ] DM、通知、検索が動く。
- [ ] ステージの作成・参加と、通話の発着信ができる。

## AI 機能を使う場合

- [ ] AI プロバイダーを登録し、起動ログでモデルの読み込みを確認した（[AI プロバイダー設定](./ai-providers.md)）。
- [ ] AutoMod の判定をテスト投稿で 1 回確認した（[AutoMod 設定ガイド](./automod.md)）。
