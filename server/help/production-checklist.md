# 本番公開前チェックリスト

サーバーを一般公開する前に確認すべき項目のまとめです。

## 1. 基本設定
- [ ] データベースに `postgres` または `d1` を設定した。
- [ ] `npm run migrate` を実行してデータベースの初期化を完了した。
- [ ] 画像保存先を設定した。
- [ ] `npm run check:config` を実行し、設定エラーが出ないことを確認した。

## 2. セキュリティ・環境変数
- [ ] `server/.env` 内のパスワードや秘密キーを Git にコミットしていない。
- [ ] 不要なテスト用アカウントやデバッグ設定が無効になっている。

## 3. 動作テスト
- [ ] アカウント登録およびログインができる。
- [ ] 投稿、画像添付、いいね、返信ができる。
- [ ] DM、通知、検索が正常に動作する。
