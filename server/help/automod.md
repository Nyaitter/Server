# AutoMod 設定ガイド

AutoMod は、ルール違反や不適切な投稿・画像を AI が自動で見分ける機能です。モデレーターの負担を減らし、コミュニティの安全を保つために使います。

先に [AI プロバイダー設定](./ai-providers.md) でサービスを登録してください。

## 設定する

`server/.env` に使うプロバイダーと判定基準を書き、サーバーを再起動します。

```dotenv
AUTOMOD_AI_PROVIDER=auto
# モデルを指定する場合だけ設定
# AUTOMOD_AI_MODEL=gpt-6-sol
AUTOMOD_PROMPT=基本的には緩めに判断してください。過度に不適切な場合のみ対応するようにしてください。
```

`auto` は登録順にプロバイダーを選びます。特定のサービスを使う場合は `openai`、`gemini`、`codex` など、登録した種類または `id` に変更します。

`server/config.json` に書く場合は `autoMod.aiProvider`、`autoMod.aiModel`、`autoMod.prompt` を使います。環境変数がある場合はそちらが優先されます。モデルを省略すると、プロバイダーの既定モデルが使われます。

## コミュニティルールを反映する

サーバーのルートまたは `server/` にルールファイルを置くと、AutoMod が全文を読み込み、規約に沿って判定します。

## 判定と自動処置

| 判定 | 処置 |
|---|---|
| `<safe>`（安全） | 通常どおり公開されます。 |
| `<low>`（軽度） | 投稿にワンクッションが付きます。 |
| `<middle>`（中度） | 投稿が限定公開になります。 |
| `<high>`（高度） | 投稿が限定公開になり、ワンクッションも付きます。 |

処置を行った場合は、投稿者に通知が届きます。
