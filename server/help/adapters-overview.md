# 保存先の選び方

データベースとファイルの保存先は自由に組み合わせられます。

## データベース（`DB_ADAPTER`）

| 設定値 | 保存先 | 用途 |
|---|---|---|
| `memory` | メモリ | 試用向け。再起動するとデータは消えます。 |
| `postgres` | PostgreSQL | 本番運用。 |
| `d1` | Cloudflare D1 | Cloudflare 上で運用。 |

データベースを設定したら `npm run migrate` を実行してください。

## ファイル保存先（`STORAGE_ADAPTER`）

| 設定値 | 保存先 | 用途 |
|---|---|---|
| `local` | サーバー本体のディスク | サーバー 1 台で運用。 |
| `r2` | Cloudflare R2 | 複数サーバーや大量の画像・動画。 |
